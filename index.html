問題プリント生成

「関数」「図形」を切り替えて、条件を選んでから「プリントを作成」を押してください。数値だけでなく構成自体が毎回ランダムに変わります。

出題される可能性がある内容: 変域 / 2点を通る直線の式 / 交点 / 三角形・四角形の面積 / 三角形の面積を2等分する直線の式 / 面積や線分の長さの条件を満たす動点の座標。
対応パターン: 垂線→直角三角形の相似・台形の面積分解 / 対角線→台形の対角線交差の相似 / 延長線→平行四辺形+延長線の相似・三角形+延長線の相似 / 比率点→中点連結の一般化。図形・補助線とも複数選ぶと、合致するパターンからランダムに選ばれます。
